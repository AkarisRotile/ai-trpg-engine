## 二、必须杜绝的（能硬拦，按优先级）

### 2.1 ★★「不是 A，而是 B」家族 —— 最高优先

用户原话：
> 「像这种『不是而是』以及各种变体是最凡人最恶心的那种句型，
>  一出现就没任何兴致了，**这种是必须杜绝的**」

**证据（用户截图）**：`三个日本人一条船，这不是巧，这是守秘人安排的`

**为什么这么致命**（要写进提示词，让模型知道"为什么"）：

1. **靠否定一个没人说过的靶子来制造洞见**——「这不是巧」：谁说是巧了？否定是空的
2. **修辞上封闭**：把答案直接给了，桌上本该留白的地方被一句收口
3. **社论/广告腔**：自媒体标题最爱这个句式，人不会这么说话

**变体清单**：不是A而是B｜这不是A这是B｜不是A是B｜并非A而是B｜
与其说A不如说B｜不在于A而在于B｜拆成两句也算｜A不是B，C才是｜真正…的是…

**判定（离线验证：命中 10/10，误伤 0/13）**：

```python
ANTITHESIS = [
    r"不是[^。！？\n]{1,24}[，,。；;]\s*(?:而)?(?:是|就是|在于)",
    r"这不是[^。！？\n]{1,24}[，,。；;]\s*(?:这|那)?(?:是|就是)",
    r"并非[^。！？\n]{1,24}[，,。；;]\s*(?:而)?(?:是|在于)",
    r"与其说[^。！？\n]{1,24}[，,]\s*不如说",
    r"不在于[^。！？\n]{1,24}[，,]\s*(?:而)?在于",
    r"(?:真正|其实)[^。！？\n]{0,12}的?不是[^。！？\n]{1,20}[，,。]",
    r"不是[^。！？\n]{1,20}[，,]\s*[^。！？\n]{1,16}才是",
]
```

**验证记录**（脚本已删）：应当命中 10 条 → 漏报 0；不该命中 13 条 → 误伤 0。
写这版时补了两次漏网，记下来免得日后精简掉：
- 「A 不是 B，**C 才是**」（`重要的不是名字，那封信才是`）
- 「不在于 A，**在于 B**」（少「而」的变体）

**正例对照**：

| 现在这么写 | 改成这样 |
|---|---|
| 三个日本人一条船，这不是巧，这是守秘人安排的 | 仨日本人同一条船？这也太巧了 |
| 不是害怕，是兴奋 | 有点怕，但更多是兴奋 |
| 我这角色是先问「他为什么找我」的那型 | 我这角色见谁都得先问一句「他找我干嘛」 |

**处置**：全频道硬禁 → 静默重写一次 → 还命中就按对照表拆句。
⚠ 这条**难做字面兜底**，重点必须放在提示词 + 重写上。

### 2.2 破折号 —— 全频道禁，改断句

**结论怎么一步步改过来的**（记下来免得走回头路）：

| 轮次 | 结论 | 被什么推翻 |
|---|---|---|
| 一 | 只禁玩家层 `ooc` | 用户说"倾向完全禁用" |
| 二 | 也禁 KP 的 `ooc`，`narr` 放行 | KP 开场那段有两处破折号 |
| 三 | 差点把 `act` 也划进去 | 用户给了一段"有感觉的"叙述 |
| **四（定稿）** | **全频道禁** | **用户亲手重写，证明可以完全省略** |

**决定性证据**：

原版：`继续画——画得很烂，海这东西一画就假`
用户改写：`就继续画着。`（换行）`画得很烂，海这东西一画就假。`

**真正的规律**：
> **破折号想做的事（停顿、转折、补充），交给换行和句号。**
> 破折号是一种偷懒的省略写法；中文里断句本来就更自然。

**判定**：`——`｜`—`｜`–`｜`--`，频道：`act`/`ooc`/`free` + KP 的 `narr`/`ooc`

**兜底替换**（按用途分）：停顿/转折 → 断句；补充/插入语 → 「，」或括号。
模型重写失败时一律换「，」并补句号（只求读得通）。

### 2.3 Markdown 加粗泄漏

**证据**：`**在这条船上干什么**`、`**上路前你往口袋里塞的那样东西**`

**性质**：比破折号更刺眼。**根因是我的提示词文件本身全是 markdown，模型照学了。**

**判定**：`\*\*[^*\n]+\*\*`；顺带查 `#` 标题、`- ` 列表、`> ` 引用、`|` 表格

**处置**：同破折号；兜底**直接删 `**`**（删了不影响可读性，比破折号安全）

### 2.4 问卷式排比提问

**证据**：
> （你们彼此认识吗？还是这十一天里只打过照面？谁先搭的话，谁一直在躲？
>  这一夜你们是各回各舱，还是有人在餐厅坐着、有人上甲板抽烟、有人去找船员打听目的地？）

一条里 4 个问号、两组「A 还是 B」。这不是人在问，是**把规则书上的清单念出来**。

**判定**：单条 `？` ≥ 3，或「A，还是 B」≥ 2 组

**处置**：提示词写死"一次最多问一件事"；哨兵统计命中则重写

### 2.6 派活／纠正的口气

**证据**：`别一上来就审人`｜`先问那个好说话的`｜`照片先捂着，等混熟了再掏`

**判定**：`<ooc>` 里出现祈使句指挥别人——`别[^，。]`／`你去…`／`先…再…`

**处置**：提示词写死"**不对别人下指令**，只说自己的打算"；哨兵命中则重写

### 2.7 别讲依据、别解释自己

用户原话：「如果做什么都要『摆事实』『讲依据』的话，会非常没意思」

桌上的人**不解释自己为什么这么做**。截图为证：

> ❌「先问那个好说话的，月刊那位。冬野你想知道谁发的信，我也想，
>    顺嘴就能带出来，别一上来就审人。」
> ✅「我先跟那位聊聊。」

> ❌「照片先捂着，等混熟了再掏」
> ✅「照片我先收着。」

**理由留在心里**——那是 `<think>` 的活，不是桌边说的。
`<ooc>` 里只说结论和打算，不说推理过程，也不给别人解释。

顺带：这条也解释了为什么之前的输出读起来"不像朋友"——
一直在**论证自己**的人，本来就不好相处。

### 2.8 撇清 / 拒绝 / 对抗的口气

**证据（用户圈图）**：`别指望我`｜`我不去`｜`别催`｜`谁挨打谁上`

用户原话：「这种也是我比较不喜欢的句式，如果是我的话，
我是不喜欢和会这样说话的人交朋友的」

**本质**：对自己能力的消极宣告 + 对别人的防御。
和"冲"是同一个根（§4.1 的关系设定缺失），但表现不同——冲是**进攻**，撇清是**撤退**。

**判定**（低误伤）：

```python
DEFENSIVE = [
    r"别指望我", r"我(可)?不(去|管|掺和|参与)", r"别(催|问我)",
    r"谁(挨打|爱)谁上", r"随便(你们|吧)", r"我(先)?撤(了)?",
]
```

**处置**：提示词 + 哨兵重写；并按 §4.1③ 的改写表把句子转成参与式。
**★ 但要和"自嘲"区分开**——「我废了」是好句子，「别指望我」是坏句子。
差别在**人还在不在场**（详见 §4.1）。

## 三、只能靠示范的（不做硬拦截，说明理由）

### 3.1 工整排比 / 对仗 —— 最难抓、也最烂俗

**证据**：
> 说话的时候我留意他们的眼睛——谁先接话，谁低头看杯子，说到哪一句的时候手指会动一下。
> 画怪谈那位谈吐挺松，可一提到「这次是谁找上你的」，他就笑着岔开了去说海上的天气；
> 另一位是写月刊稿的，答得很利索，利索得像提前打过稿。

拆成三处：**三项并列** ／ **分号对仗** ／ **顶针式收束**（「利索得像提前打过稿」）

**本质**：不是某个词的问题，是**"太对称、太正好"**。真人的观察是零碎、不均匀、带废话的。

**★ 界线**：禁的是**排比/对仗结构**，**不是比喻**。
「利索得像提前打过稿」这句比喻本身不烂，烂的是它被放在工整对仗的结尾当收束。
> 这条界线必须写明，否则很容易像破折号那样过度纠正，把用户喜欢的灵光一起删掉。

**处置**：正则一抓就大面积误伤 → **靠正反例 + 量化指标**（§10）。
低误伤的子型（§2.5）仍进哨兵。

**改写示范**：

| 现在 | 改成 |
|---|---|
| 谁先接话，谁低头看杯子，说到哪一句的时候手指会动一下 | 我盯着他们的眼睛看 |
| …谈吐挺松…；另一位…，答得很利索，利索得像提前打过稿 | …挺松，可我一问「这次是谁找上你的」，他就笑着说起海上的天气。另一个人答得太顺了 |

改动的实质：**三项砍成一项、对仗拆开、顶针收束删掉**。内容没少，只是不再"处处恰好"。

### 3.2 括号里写规则，而不是说话

**证据**：`（先说谁在哪、在做什么，再往下走。）`／`（是什么你自己知道就行，不用告诉别人。）`
这是**给系统的指令**混进了给玩家的话。误伤风险高 → 只靠提示词与示例。

### 3.3 编剧腔词汇

`我台词里说的…`——「台词」是编剧/演员的词。
同类：戏份／人设弧光／剧情线／叙事。写进黑名单，不做硬拦。

### 3.4 一条里堆多个括号

`(开场了开场了)  (三个日本人…)`——真人是一条一条发的。
影响不大（界面按条显示），提示词里提一句即可。

## 四、★ 根子上的三件事

### 4.1 ★★ 他们是朋友，不是同事（「冲」的根因）

用户原话：「整体来说的话，我感觉他们说话都很**冲**，不太像朋友其实」

**证据一：提示词里从来没说过他们是朋友。**
全文搜「朋友」，命中的全是研读室/散场（"守秘人 ↔ 导演"的关系）。
**同桌玩家彼此是什么关系，一次都没定义过。**
而这桌人明明有跨周目记忆——记得彼此的梗、上局谁演了谁、`PlayerCard` 里存着
"对其他人的看法"。**那本来就意味着他们是一群长期牌友**，这个设定
我一直在用机制实现，却从没写进提示词。→ 模型按"陌生人组队做任务"演 → 冲。

**证据二：我第三次犯「举例即示范」。**
`TABLE_REGISTER` 的正例 11 条里，**6 条是断然拒绝/祈使/推脱**
（我不去、别催、谁挨打谁上、别指望我×3）。想教"短"，教出了"冲"。

**证据三：整个清单里没有一个"附和"的例子。**
真人朋友聊天里附和占很大一块。我的例子全是"表达自己立场"。

**证据四（用户圈图，这条最重）：被圈出来的正是"撇清"家族**

用户在我那段示例里圈出五处：
**「我不去」**、**「别催」**、**「别指望我」×2**、**「谁挨打谁上」**

> 「这种也是我比较不喜欢的句式，如果是我的话，
>  我是不喜欢和会这样说话的人交朋友的」

拆开看，它们是一个家族：

| 句子 | 本质 |
|---|---|
| 别指望我 | **预先撇清责任** |
| 我不去 | **断然拒绝** |
| 别催 | **对抗** |
| 谁挨打谁上 | **阴阳** |

共同点：**对自己能力的消极宣告 + 对别人的防御**。

**★ 用户给了一个我一直缺的验收判据：**

> **这句话说出口，桌上的人愿不愿意跟你玩？**

**★ 由此划出一条之前没分清的界线：**

| | 例 | 为什么 |
|---|---|---|
| ✅ **自嘲** | 「我废了」「我这角色就是个摆设」 | 好笑，**而且人还在场** |
| ❌ **撇清** | 「别指望我」「我不去」 | 把责任推掉，**人不在场了** |

同样是说自己不行，前者让人想跟你玩，后者让人不想。
**差别不在"负面"，在参不参与。**

**① 关系设定（一句话，缺了就全错）**
> 你们是**一起玩过好几局的老相识**。上局谁演了什么、谁说过什么蠢话，
> 桌上都还记得。所以你们说话不用客气，可以互损、可以跑题、可以说废话、
> 可以当场笑出来。**不是开会，不是组队任务。**

**② 禁止"派活/纠正"的口气**（见 §2.6）

**③ 禁止"撇清/拒绝"的口气** ← 新增，配一条改写表

| 撇清写法（禁） | 改成（参与式） |
|---|---|
| 我侦查才25，别指望我 | 我侦查不行，谁来搭把手 |
| 我不去 | 我有点不敢进去……你们先进，我在这儿望风 |
| 别催 | 等一下，我看完这块就来 |
| 谁挨打谁上 | 我血薄，你们护着我点 |
| 我枪法一般，别指望我一枪一个 | 我枪法一般，能不动手就别让我上 |
| （同类）别问我／我不管／随便你们／我不掺和 | 换成正向表态或求助 |

规则：**要提数值就用来求助或自嘲，不用来撇清。**
而且**数值尽量别提**——真人桌上大半的话根本不带数字。

**④ 补一整类：行动 / 附和 / 打趣 / 关心 / 废话**

真实桌上最常出现的是**行动表态**，我的旧清单里一条都没有：

```
行动：  （我来我来）（那我上）（我先看看）（我去那边问一句）（我跟着他）
附和：  （对对对，我也这么想）（我也去）（行啊）（你这么一说确实是）（我怎么没想到）（哈哈哈哈）
打趣：  （你可拉倒吧）（就你？）（你上次也是这么说的，然后呢）（别装了）
自嘲：  （我废了）（我这角色就是个摆设）（行吧，我又没帮上忙）（我只能喊加油）
关心：  （你歇会儿，我来）（别硬上啊）（要不等天亮再说）（你还好吧）
废话：  （等下，我外卖到了）（啊这）（？？？）（我猫踩键盘了）
```

### 4.2 示例库建设规则（防第四次犯同一个错）

1. 示例按**类别**建，不是一个平铺的列表
2. 每次改完**数一遍各类占比**——不能某一类占到一半
3. 最低配比（草案）：
   | 类别 | 条数 |
   |---|---|
   | 行动表态 | ≥ 4 |
   | 附和 | ≥ 3 |
   | 自嘲（**人还在场的那种**） | ≥ 2 |
   | 打趣 | ≥ 2 |
   | 关心 | ≥ 2 |
   | 废话 | ≥ 2 |
   | **撇清/拒绝/对抗**（别指望我／我不去／别催／谁挨打谁上） | **0** |
4. **正例本身就是规格**——写例子时要问："如果模型只学我的例子，会变成什么样？"
5. **终检问题（用户给的判据）**：逐条读一遍，
   **这句话说出口，桌上的人愿不愿意跟你玩？** 不愿意的，一条都不能留。

> 这条规则是被打脸三次换来的：
> ① 例子生硬 → 改内容 ② 例子偏"冲" → 改倾向 ③ 例子是"撇清" → 直接删干净。
> 前两次都只改了"内容"，没改"姿态"。

### 4.3 `<act>` 的写作规范（拿用户亲手改写的版本当标准）

**原版（模型写的）**：
> 我靠在船尾栏杆上，速写本摊开，给那道白沫勾线。铅笔尖有点钝，我拿指甲刮了两下，
> 继续画——画得很烂，海这东西一画就假。
> 画到一半我抬头，往甲板两头各看了一眼。然后合上本子，把铅笔别在耳后。
> 「去餐厅坐会儿吧。」我说，往走廊那边走。

**用户改写（这才是标准）**：
> 我靠在船尾栏杆上，摊开速写本，给那道海上的浪勾线。铅笔尖有点钝，
> 随便在纸上磨了磨就继续画着。
> 画得很烂，海这东西一画就假。
> 画到一半不想画了，我抬起头来，看了看甲板两边。然后合上本子，把铅笔揣兜里。
> 「去餐厅坐会儿吧。」
> 我想着，然后往走廊那边过去。

**逐处对比**：

| 原版 | 改写 | 规律 |
|---|---|---|
| 速写本**摊开** | **摊开**速写本 | 语序像说话 |
| 我拿指甲**刮了两下** | 随便在纸上**磨了磨** | 动词更随口 |
| 继续画**——**画得很烂 | 就继续画着。（换行）画得很烂 | 破折号 → 断句 |
| 画到一半我抬头 | 画到一半**不想画了**，我抬起头来 | 允许**半途而废** |
| 把铅笔**别在耳后** | 把铅笔**揣兜里** | 去掉刻意的小精致 |
| 「…」我**说**，往走廊那边走 | 「…」（换行）我想着，然后往走廊那边过去 | 换行替掉逗号串联 |
| —— | **「海这东西一画就假」一字未改** | **唯一那句灵光必须留下** |

**提炼成规则**：
1. **破折号的地方一律断句**
2. **用词偏口语**（磨了磨／揣兜里／抬起头来）
3. **允许半途而废**——不是每个动作都要有目的
4. **别句句精雕**：整段只留**一句**有灵光的
5. **短句分行**，别用逗号把三个动作串成长句
6. **只写动作与对白，不写情绪词**

**反方向也要写清楚**：不要为了"自然"把灵光也磨掉。
「海这东西一画就假」用户明确说喜欢——**这一句不能省**。
规则是"其余放松、留一句尖的"，不是"全部写平"。

## 六、网络语气料包（可开关）

分四层，**硬规则：只许进 `<ooc>`，不许进 `<act>`**（1925 年的人不会说"绷不住"）

- 语气词/碎片：啊／诶／欸／不是／等等／？！／……
- 网络用语（克制、2026 年还在用）：离谱／绷不住／笑死／？？？／人麻了／我先撤
- 玩梗机制：接别人的词并夸张／起外号／拿上一局的事戳人／复读机式回应
- 跑题：一句跟游戏完全无关的（外卖到了／猫踩键盘）

明确避开："努力模仿真人"的痕迹——每句都完整、每句都机灵、每句都点到为止。

## 七、时间：与模组对齐

**现状（已核对）**：`engine/clock.py:347` 硬编码 `base = datetime(1925, 10, 3, 20, 0)`，
是所有"模组没写开场时刻"的兜底。用户跑的《不更文》连 `module_info.yaml` 都没有
→ 只能吃兜底；演示模组的 `start_time` 我也手写成同一个值 → **两个模组撞同一天**。

**新的优先级**：

| 顺序 | 来源 | 确定性 |
|---|---|---|
| 1 | 模组 `start_time`（已有） | 确定 |
| 2 | **从模组正文抽明确日期**（`premise`/`summary`/`scenes`/`truth`） | 确定（正则） |
| 3 | 只有年代/季节 → **由 AI 选一个日子** | 不确定，但按模组存下来 → 稳定 |
| 4 | 什么都没有 → **模组 id 的稳定哈希**挑一天 | 确定（同模组恒定） |

**AI 选日子挂在哪（核对后才定）**：
`_kp_study()` 在 `prepare()` 第 674 行，而时钟在 `GameLoop` 构造时就定好了——**更早**。
所以不能在 `resolve_start` 里等 AI。做法：
1. KP 功课输出里加 `<clock>1925-10-05 21:00</clock>`（它通读全本，最清楚从哪天开始）
2. 解析后存进**按模组**的功课记录（`data/studies/<id>.yaml`，已有机制）
3. `prepare()` 里 `_kp_study()` 之后**回填一次时钟**，条件 `session.round == 0`
4. 同模组再开团 → 功课复用 → 日子复用，**不会每次都不一样**

**界面**：模组弹窗显示开场时刻可就地改；设置里保留全局 `options.start_time`；
左栏 🕰 角标已显示最终值。

## 九、顺带修：一条假警报

**现象**：座位卡片飘红字「技能点超支…」，但**卡其实是合法的**。

**证据（离线复现，数字与截图一致）**：

```
真壁 千夏：预算 职业 288 + 兴趣 100 = 388 → 修复后 288/288、100/100 → 合规 ✓
宫原 透：  预算 职业 190 + 兴趣 180 = 370 → 修复后 190/190、180/180 → 合规 ✓
```

**根因**：`run_chargen` 返回的 `warnings` 装的是**缩放之前**的违规清单，
`turns.py` 存进 `chargen_warnings`，`_seat_states()` 原样交给界面 → 红字。

**改法**：
1. `warnings` 只放**修复后**的事；修复前的违规单独存字段
2. 界面改中性文案：**「技能点 487 → 已按预算缩放到 388（职业 288 + 兴趣 100）」**
3. 去掉 `build_character_from_sheet` 里那次多余的 `repair_sheet`
4. `已自动修正` 用中性/绿，真·未解决才红

**更值得记的教训**：我的自检只验"卡合法"，**从没验"界面上告诉用户的话是不是真的"**，
所以它天天全绿，用户看到假警报。
